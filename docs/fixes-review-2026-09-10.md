## 2. 项目归档目录迁移

- 输入边界统一解析原生绝对路径、外层引号、本地 `file:///` URL、`~/` 和终端拖拽产生的转义字符。
- 针对未挂载的网络 URL、跨操作系统的路径和无效路径给出明确错误。
- 保留目录嵌套、已有目标、符号链接、版本、文件校验与失败回滚等原有保护。
- 临时目录测试覆盖多次迁移、原下载链接、未索引文件和失败后源目录保留；未迁移用户实际项目文件。
- 用户补充路径为 Windows 的 `D:\QuotePlatform\Test Project`；已确认它在原生 Windows 上属于绝对路径，并加入精确解析及 JSON 传输回归。
- 补修 Windows 目录刷新与旧文件只读句柄刷新兼容性，保留新副本写入刷新；补修盘符或共享根不可访问时的父目录查找死循环。
- 保留 POSIX 只读文件迁移支持，并补齐中断恢复时复用目标副本的落盘检查。
- 新测试先复现了根目录循环和只读句柄刷新失败，修正后通过。Windows 部分采用路径分支与句柄规则模拟，尚未在用户 Windows 实机复现“地址不完整”的原始提示，不能断言该提示的直接根因。
- 主要代码：`server/archive-folder-path.mjs`、`server/project-files.mjs`。

## 3. 报价模板英文界面与输出

- 模板编辑器、选择器、冲突详情和客户预览去除独立中文译文字段，模板字段标签使用英文。
- 标准报价 Excel 不输出内置中文标签、模板译文和假设译文；公司模板映射不再提供这些译文字段。
- 旧项目及历史快照继续兼容。客户名、项目名、条款和假设正文保持用户原文，不自动删除或翻译。
- 主要代码：`features/master-data/quote-catalog-view.tsx`、`features/quote/export-quote-workbook.ts`。

## 4. BU 公司编码

- Master Data 的 BU 设置增加可选 `BU Code`，支持编辑、保存和搜索。
- 编码允许为空或重复，只作人工对应公司的参考；记录 ID、BU 匹配和分成计算不使用编码。
- 编辑编码不会改写既有项目的成本或分成快照。
- 主要代码：`features/master-data/profit-share-editor.tsx`、`features/quote/profit-share.ts`。

## 5. Cost 引用主数据 BU

- 人员行、批量录入默认值、Excel 导入默认值、分包和额外差旅统一从已保存的活跃 BU 中选择。
- 显示 BU 名称及公司编码，成本记录仍保存 BU 名称。
- 历史、停用或未匹配的已有值继续显示，不因打开界面而清空。
- 未保存的主数据草稿不进入选项；已锁定成本保持不可编辑。
- 主要代码：`features/master-data/business-units.ts`、`features/master-data/business-unit-select.tsx`。
