# 手工报价目标总价

`Target pricing · 逐条定价` 可保存折扣及税前的目标总价，再把金额分配到客户报价明细。加载旧报价不会重算已保存单价；成本版本保持不变。

1. 选择逐条定价，输入目标总价，按 Enter 或移开焦点应用。
2. 调整各条 `Ratio 比例`，例如 2:1；比例是相对权重，无需加起来等于 100。
3. 直接修改某条 `Unit price` 后，该行自动勾选 `Fixed`，其他条目按比例分配剩余目标。取消勾选可恢复该行按比例分配。
4. 目标旁边显示明细合计及剩余差额，金额相符时显示 `Matched · 已达目标`。旧报价可点击 `Rebalance · 按比例分配` 启用目标分配。

新报价和模板样例的税率默认是 0%；已经保存的税率与历史报价保持不变。

- `manualTargetPrice`：可选，0 至 1,000,000,000,000，最多两位小数。未设置时，保持原有手工单价合计行为。
- `allocationWeight`：行的相对分配权重，可选，0 至 1,000,000。未设置时以当前行金额作为权重；所有未设权重的可调整行金额均为 0 时，按行均分。
- `priceFixed`：可选。固定行保留当前单价，其金额先从目标总价扣除，其余金额分配到可调整行。

分配结果按现有金额规则计算并核对到分，数量和单价最多保留四位小数。如果固定行超过目标、全部行锁定且金额不符、显式权重全部为零，或当前数量与单价精度无法凑齐目标金额，返回错误并保留原行内容。

手工行合计必须与已设置的目标总价相等，才能导出客户报价。例如目标 250，明细 100 + 150，整单折扣 10，GST 为 0%，则客户税前与税后总价均为 240。修改目标但尚未更新明细时可以保留草稿，客户文件导出会阻止金额不一致。

项目只修改 GST、折扣等字段时，现有目标、行权重和固定状态会保留。报价历史只记录实际输出的描述、数量、单位、单价、金额及商业条款；客户 Excel 和历史明细不携带内部权重或固定标记。后续修改草稿不影响已生成的报价记录或已确认成本版本。
