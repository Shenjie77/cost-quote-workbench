# 报价明细逐行定价

报价总价由明细合计得到。每行独立设置 **Target GP %** 或 **Price / Unit**，上方 **Actual Sales GP** 只读显示最终报价的实际毛利，不再另外输入整体目标 GP。新生成的成本明细默认 GP 为 **50%**。

## 明细字段

| 字段          | 含义与行为                                                                                                                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cost          | 该行分摊的含风险项目总成本，所有行成本合计与当前成本版本一致。                                                                                                                                      |
| Weight %      | 该行 Cost ÷ 项目总成本。Custom lines 可修改；其他行按原成本比例分摊剩余权重，原权重全为零时均分。单行固定 100%，Scope / Item 的成本占比仍由成本表决定。修改后按明细 GP 重算售价，固定单价保持不变。 |
| Quote share % | 该行金额占明细合计的比例；默认随成本占比，可单独调整。                                                                                                                                              |
| Target GP %   | 该行扣除 BU 分成后的目标销售毛利；修改后重新计算该行单价。                                                                                                                                          |
| Price / Unit  | 客户单价；直接修改后固定该单价，行 GP 按新金额计算。                                                                                                                                                |
| Amount        | 数量 × 单价，按报价金额精度计算到分。                                                                                                                                                               |
| Lock          | 调整报价比例时，保留该行的比例或单价。                                                                                                                                                              |

Cost 包含人员、分包、差旅、补充成本及分摊风险。修改售价、GP 或报价比例不会改写成本输入，也不会把新的售价当作成本权重。自定义新增行初始 Cost 为 0；删除行后，项目成本会重新分配到剩余行，需检查新的逐行价格和毛利。

## 调整 GP、单价与报价比例

- 修改一行 GP，只重算该行价格；其他行保留自己的定价，明细合计随之变化。GP 默认 50%，支持 0–95%；GP 加加权 BU 分成率必须小于 100%。
- 直接修改单价，固定该单价并解除该行的比例锁定，系统据此显示该行毛利。更改固定单价行的数量会改变其金额；按 GP 定价的行则重新计算单位价格以维持该行 GP。
- 修改一行报价比例，以**当前明细合计**为分配基准，并锁定该比例。系统先保留固定比例行和固定单价行，剩余金额由所有未锁定行均分；Weight 成本占比不变。
- 同一行不能同时锁定比例和单价。直接编辑 GP 会解除这两类锁；取消 Lock 后，该行可以参与之后的比例分配。比例锁只用于比例重分配，不会把上方总额变成固定目标。
- 切换 Single line、By Scope 或 By cost item 会明确重新生成相应成本行，目标 GP 从 50% 开始。切换 Custom lines 保留当前行供编辑。

例如三行 Cost 分别为 20、30、50，无 BU 分成，50% GP 得到金额 40、60、100，明细合计为 200。直接将第一行单价设为 50 后，该行固定，总价变为 210；再将第二行报价比例设为 20%，金额为 42，第三行得到剩余的 118。成本分配仍是 20、30、50。

数字输入在 Enter 或离开输入框时应用；未完成的小数输入暂存在输入框内，Esc 取消本次编辑。固定比例与固定单价占用超过总额、全部行锁定却无法分配剩余额，或数量与四位小数单价无法准确分配到分时，会显示错误，不保存失败的比例分配或生成客户文件。

## 总价与整体 GP

```text
Line Total       = 所有明细 Amount 合计
Quote Total      = Line Total − 整单 Discount
Profit Share     = Quote Total × 当前加权 BU 分成率（按金额精度取值）
Sales Profit     = Quote Total − 含风险总成本 − Profit Share
Actual Sales GP  = Sales Profit ÷ Quote Total × 100%
```

行 GP 按折扣前的该行金额计算；上方整体 GP 按折扣后的最终报价计算。因此设置整单折扣后，两者可能不同。最终报价为 0 时，整体 GP 按现有规则显示为 0%。整单折扣不能超过明细合计。

## 客户输出与历史

点击 **Preview · 客户预览** 查看客户明细、服务报价、折扣、Quote Total 和条款。预览只改变显示状态；生成 XLSX 前仍需确认成本版本并通过报价校验。客户明细只输出描述、数量、单位、单价和金额，不含内部 Cost、Weight、报价比例、GP 或锁定字段。

GST/税输入、当前报价税计算和标准客户文件税行均已移除。新报价保留内部兼容字段，但税额为 0，旧 before/after 总额字段都是同一最终报价。已保存的历史报价、原税率字段和既有输出快照不被追溯覆盖。旧系统税假设不再加入新输出，用户自己的条款不会被关键词删除。

客户 Excel 新映射只显示一个 Quote Total。旧总额映射仍接收最终报价，只有已映射的税率和税额格被清空；未映射的静态税文字、公式和其余客户内容保留。具体配置见[客户 Excel 报价模板](customer-excel-quotation.md)。

## 保存字段兼容

新逐行定价使用 `pricing.manualPricingBasis: "line-gp"`，不再由 `manualTargetPrice` 控制总额。`lineSourceMode` 记录明细来自单行、Scope、成本条目或自定义。

- `costWeight`：独立保存的成本分配基础；展示的 Weight 是由实际分摊 Cost 得到的百分比。
- `targetGrossMargin`：逐行目标 GP；没有该值的行保留已保存的单价。
- `allocationWeight` 与 `allocationFixed`：用于报价比例重分配时的百分比及锁定标记。
- `priceFixed`：固定单价，和比例锁互斥。

没有新标记的旧手工报价，以及旧 `"gp"` 和 `manualTargetPrice` 约束仍按兼容规则读取；仅打开、预览或导出不会重写已保存的行。用户明确编辑或切换明细定价后，才保存新的逐行定价意图。历史记录始终保留当时输出快照。
