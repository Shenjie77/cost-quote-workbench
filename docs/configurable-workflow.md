# 可配置项目流程

在 **Master Data → Workflow** 编辑统一流程模板。每个节点设置名称、默认负责人、SLA、提醒开关及办理要求；页面不展示内部编码，改名称不会改变节点身份。

- 并行组使用“Move Phase Up / Move Phase Down”整体调整顺序，组内节点箭头只调整组内顺序；串行节点箭头直接移动所在阶段。相邻节点填写相同的并行组名称，就会一起显示并支持同时办理，发布时仍会检查同组节点是否连续。
- 新增节点自动插入结束节点之前；结束节点固定保持最后，序号随新增和移动重新排列。
- SLA 可选工作日或自然日，范围为 1–365 天。工作日按新加坡时间周一至周五 09:00–18:00 计算，一工作日为 9 小时；高级选项可补充非工作日期。
- **必经节点**不能手动跳过，完成时须明确确认，并填写配置的每一项必填信息。发布时新增到现有项目已越过阶段的节点，按下述继承进度规则自动通过。
- **新成本轮次起点**决定新建成本 Draft 从哪里重新开始；**要求成本定稿**在开始节点前检查当前轮次成本 Confirmed；**结束项目流程**完成后停止本轮项目提醒。
- 可选节点可配置默认跳过。模板必须保留唯一轮次起点和唯一结束节点，结束节点放在最后；发布预览会检查规则和项目影响。

点击 **Preview & Publish** 查看进行中项目将采用的变更。未开始节点可同步新配置，已完成项目及历史记录保留，已完成项目不会阻止发布新模板。已开始节点默认保留原处理时限；需要迁移时，逐项目勾选并重新预览。发布会校验模板和各项目版本，避免覆盖期间发生的新变化。

- 新增节点所在阶段早于项目已有的办理、暂停或完成记录时，该新增节点自动通过。预览列明自动通过节点，发布时记录为 **Skipped**、保留 `template-sync` 来源和逐节点操作历史；这是继承项目进度，不表示曾进行人工审批，也不补造开始时间、SLA 或审批字段。
- 在当前并行阶段新增节点仍需正常办理；只有该阶段已有节点全部结束，或项目已进入更后阶段，新增并行节点才自动通过。
- 未来阶段的新增节点仍为待办，新项目和新成本轮次按已发布模板及轮次起点正常执行。历史完成轮次和成本数据不改写。
- 将**已有、未开始的必经节点**移到已记录进度之前仍会提示冲突，删除活动节点或破坏并行组连续性也仍会阻止发布；这些情况需调整模板或处理现有节点。

从 Today 或 Project List 的流程入口，或侧栏 **Project Workflow**，打开独立流程页面。默认选中当前待办；宽屏左侧按阶段和并行组展示节点，右侧只编辑一个节点；窄屏使用紧凑的节点选择框，直接显示操作区。切换节点只切换查看对象，不会推进流程。

Project Workflow 与 Cost 共用 **Open Projects** 标签栏和当前项目：切换标签时保持当前模块，切换到 Cost 或返回 Workflow 时沿用同一个项目。关闭当前标签后选择相邻项目，仅关闭标签，不删除项目记录；未保存成本先保存，未保存的流程输入在切换项目时提示确认。

新项目完整采用创建时已发布的全部节点及规则。显式配置的节点即使沿用早期系统编码，也不会被旧版兼容逻辑删除；名称、顺序和关键节点规则以配置为准。

- **Start Step / Start Parallel Group**：开始节点；并行组内待开始节点一起进入办理状态，并计算各自的 SLA 截止时间。
- **Complete Step**：填写必需信息；必经节点还需勾选实际核对确认。保存成功后自动选中下一项待办，优先处理仍在办理的并行节点。
- **Save Update**：直接维护负责人、跟进日期、节点信息和进展说明，不推进流程。未保存内容按节点保留，切换节点或通过 **Open Cost** 查看本轮成本后返回仍可继续填写。
- **More Actions** 收起较少使用的 **Pause / Skip / Reopen**；暂停需填写原因及恢复跟进日期，**Resume Step** 恢复后由系统调整处理时限。跳过和重开需填写原因，不能绕过必经节点或破坏后续已完成的关键节点。

卡片显示开始时间、截止时间、紧急程度和已登记信息。提醒可以直接定位到对应节点。整轮完成后不再允许修改该轮节点；需求变化时新建成本版本。流程历史保留操作当时的必填信息、开始时间及截止时间，重开后仍可核查原记录。

Proposal、Scope、技术资料版本和快捷链接集中在顶部项目信息栏；点击 **Edit Info** 就地编辑并保存。原 Company Platform Link 继续作为 **iSales / Company** 入口，**CPQ** 使用单独的项目链接。有效的 HTTP/HTTPS 地址可直接在新标签页打开；未填写或非网页地址保留文本显示。资料保存不会代替节点开始或完成，也不重算已锁定成本。正式申请和审批仍在公司平台办理。

页面地址会记录项目及所选节点，可复制链接或刷新后直接定位，打开链接不会更改流程。页面无未保存输入时自动检查最新记录；有输入时保留原填写基础并提示外部更新。**Refresh** 在存在未保存输入时提示确认丢弃；切换到另一个项目或关闭浏览器时也保护未保存内容。

Today 的 **Project Workflow Distribution** 从已发布的全局 Workflow 读取节点名称、顺序和并行组，数量按项目实际记录的节点统计。发布后立即刷新；页面停留期间和重新聚焦时也会检查更新。未发布的编辑草稿不影响 Today。已从全局移除、但仍有项目历史或当前进度的节点单独显示在 Other recorded nodes，原项目记录不改写。

节点配置和执行界面采用英文控件，名称优先使用 Name，未填写时显示已有中文名称；用户维护的中文资料和历史记录保留。成本页顶部版本信息框也采用英文，成本输入及报表项目的中英文不变。
