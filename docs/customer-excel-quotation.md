# 客户 Excel 报价模板

客户 `.xlsx` 可以在部署工作台的电脑本地上传和配置，不需要将公司文件提供给开发人员。原文件以不可变资产保存在本地 SQLite 中，现有数据库备份会同时包含模板文件；项目 JSON 只保存模板引用和填写位置。

## 配置一次，后续复用

1. 打开 **Master Data → Quote Templates**，新建客户模板，并设置客户完整名称。
2. 在 **Customer Excel layout** 上传 `.xlsx`，选择报价工作表。
3. 指定一条完整报价明细的样板行，以及描述、金额、数量、单位和单价所在列。描述与金额必须配置；其他明细列可以省略。
4. 配置报价编号、客户、项目、Quote Total（报价总额）、有效期和付款条款共六个必填单元格。地址均填写原模板的位置，例如 `B5`，不是扩展后的行号。存在整单折扣、T&C 或已选假设时，也要配置对应单元格，避免导出遗漏已确认的商业内容。
5. 点击 **Test with sample rows**，用三条虚构明细检查 Excel 的格式、公式和打印效果。此操作不会新增项目文件或报价历史。
6. 点击 **Apply mapping**，系统先试填并验证实际模板结构，再应用配置；最后点击 **Save this tab** 保存全局模板。

现有项目保留自己的模板快照。需要采用新配置时，按既有“应用主数据”流程将报价模板应用到项目，再在 Pricing & Quote 选择模板。历史报价保存原模板引用与明细快照，不随全局模板修改而变化。

## 报价明细方式

| 模式 | 行为 |
| --- | --- |
| Single line | 将含风险成本分配到一条报价行。 |
| By Scope | 相同 Scope 描述归为一组，忽略大小写和重复空白。 |
| By cost item | 成本条目分别展开为报价行。 |
| Custom lines | 保留当前明细，再修改描述、数量、单位、逐行 GP 或单价，也可新增报价行。 |

明确选择 Single line、By Scope 或 By cost item 会重新生成成本对应的明细，逐行目标 GP 从 50% 开始。自动生成行以 `1 lot` 为报价数量，不把内部人天或站点数量默认当作销售数量。

内部明细的 **Cost** 是含风险总成本分摊额，**Weight %** 为成本占比；**Quote share %** 是可调整的报价比例，初始随成本占比。修改逐行 GP 或 Price / Unit 后，服务报价按行金额合计。修改报价比例时，以当时的明细合计为分配基准，保留已锁定行，由其余未锁定行均分剩余金额。上方整体 Sales GP 根据折扣后的最终报价和 BU 分成只读汇总，不作为另一份可输入目标。

金额按分分配和核对，明细合计必须等于折扣前服务总价。分包、差旅、补充成本和风险计入成本分摊，新增自定义行初始成本为 0。客户文件仅含描述、数量、单位、单价和金额，不增加内部 Cost、Weight、报价比例、GP、锁定或利润分成字段。详细规则见[逐条定价](manual-quote-target-pricing.md)。

一条明细占一行；多条明细复制样板行格式并插入新行，下方合计和条款随之下移。未使用客户 Excel 的详细模式在标准报价文件中新增 `Quotation Details` 工作表，汇总页显示服务报价、折扣和单一 Quote Total。

## 旧模板与税字段兼容

新配置界面只提供一个 **Quote Total**。旧模板的 `quoteBeforeTax` 和 `quoteAfterTax` 总额映射仍可使用，两者都填写同一份最终报价。已保存的 `gstPercent`、`gstAmount` 映射格会被清空，包括其旧公式和值；格子格式和原始模板资产不变。

系统不对客户工作簿做文字搜索删除。未映射的税字样、静态说明、公式和其他客户内容保持原样，需要改变这些文字时应修改模板原件后重新上传。新报价不再计算或显示 GST/税；历史报价及兼容字段保留原数据，不追溯改写已出具记录。旧系统税假设不再进入新客户输出，用户自己的条款按原文保留。

## 模板适用范围

- `.xlsx` 原文件不超过 10 MiB，解压后不超过 50 MiB，模板工作表和映射不超过 20,000 行；单次报价最多 1,000 条明细。
- 样板采用一条普通单元格行，可以横向合并；纵向跨行合并不适合作为重复行。现有预留空白行不会自动识别为可替换明细区，建议模板副本只保留一条样板明细。
- 支持常见样式、行高、图片、普通 A1 公式、合计范围、页脚合并、打印范围、分页及常见数据验证和条件格式。Excel 打开导出文件时重新计算公式。
- 图表、透视表、宏、外部链接、嵌入对象、文本框/形状、数组公式、结构化引用等不支持的结构会明确报错。可在公司电脑上另存一个普通报价模板副本，把文本框改为单元格文字，把表格对象转换为普通区域。
- 未映射的模板文字按原样保留。首次应用各客户模板时，应通过示例试导出核对原有文字及打印效果。通用验证无法判断未映射文字是否属于旧客户。

## 自检与验证记录

实现包含本地二进制上传/下载、哈希去重、原件不可变、SQLite 备份恢复、工作簿增行、公式/合并/图片/打印范围、必要商业字段、四种明细模式、金额对账、异步模板切换与导出历史回归测试。测试文件均由虚构数据生成。

审查发现并修复了商业字段可能漏写、极高行号导致不必要内存分配、模板切换时晚到上传响应、旧 CLI 模板历史快照记录不准确等问题。

Lint 对 Node 自带测试注册函数作了窄范围配置：只认可 `node` 类型包的 `test` 调用由测试运行器管理，不关闭其他异步调用检查。此行为依据 [Node 测试运行器说明](https://nodejs.org/api/test.html) 和 [已知安全调用配置](https://typescript-eslint.io/rules/no-floating-promises/#allowforknownsafecalls)。
