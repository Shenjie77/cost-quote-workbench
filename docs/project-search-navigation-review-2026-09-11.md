# 项目搜索与刷新导航验收

## 修改清单

- 表头搜索支持 Proposal Number、Project Name 和当前 Workflow 名称、代码、状态；保留项目 ID、客户、版本搜索。结果以下拉列表展示名称、编号及当前流程。
- 当前流程按有效待办及待启动节点匹配，支持并行节点、中英文状态和大小写混合输入；历史已完成节点不会误命中。
- 点击结果只切换项目上下文，保留所在页面与 Cost 子页；Workflow 页面加载所选项目的对应流程。支持方向键、Enter、Esc、中文输入法及重复点击保护。
- 项目索引增加可选 Proposal Number，兼容未填写编号的旧数据，并同步当前编辑及远端刷新得到的编号。
- 当前浏览器标签页记住页面、项目、已打开项目、Cost 子页和 Master Data 页签；刷新优先恢复当前历史记录，现有 Workflow 深链接优先。
- 已删除项目回退至可用项目并保留页面；无项目时独立打开的 Master Data 也可恢复。浏览器存储异常不阻止业务操作。

## 功能保护与自检

- 搜索切换复用已有业务保存保护；保存失败时保留当前项目及搜索输入，不丢弃未保存编辑。
- 导航偏好仅保存在浏览器历史和本标签页会话存储，不写入项目成本、定价、流程结果或主数据。
- 成本表年份、分组、列显示沿用已有 Save Configuration 机制；本次自动恢复的是页面及子页。
- 浏览器联调发现纯逻辑与组件同名会使 Vite 错误解析为组件自引用，已改为独立的 `project-search-model.ts`。
- 取消将可选的显示配置保存作为项目切换门槛，避免存储配额不足时不能切换项目。
- 工作流异步保存、加载、项目选择各阶段都验证最新导航意图，已过期的响应及错误不能覆盖新页面；浏览器返回与 hash 变化优先采用最新位置。
- Workflow 初始加载失败时显示错误和可点击的 Retry，避免重试入口被加载期间的禁用区域挡住；独立 Master Data 的恢复不会覆盖明确的 Workflow 深链接。

## 验证记录

- 完整回归 800 项通过，0 失败、0 跳过；TypeScript、Lint、修改文件格式、差异检查及最终生产构建均通过。
- 自动化覆盖索引持久化及 CLI 合同、当前/并行/完成/暂停流程匹配、键盘/鼠标/IME 交互、失败重试、刷新恢复、深链接优先、历史状态兼容、损坏或禁用的浏览器存储。
- 浏览器实测 Cost → Summary → 搜索项目 → 切换 → 刷新：项目与 Summary 均保留。
- 浏览器实测当前流程关键词下拉展示、Workflow 页面跨项目切换与刷新后的项目/节点恢复、Master Data 报价模板页签刷新恢复；修复后没有新增浏览器运行错误。
- 验收使用已有项目进行导航，未新增成本行、修改业务输入、完成流程或生成报价。
