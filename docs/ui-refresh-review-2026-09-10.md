# 界面与交互体验优化记录

## 本次范围

保留现有操作流程与业务行为，对工作台的展示层进行统一。没有修改业务领域代码、计算公式、接口、数据库结构、导入导出格式、成本锁定条件或工作流推进条件。

## 修改清单

- 统一浅冷灰背景、白色内容面板、海军蓝主色及青绿色强调，统一圆角、边框、轻阴影、字号和间距。
- 侧栏突出页面名称与当前选中项，详细说明保留在悬浮提示中；顶部导航、项目标签与保存状态采用同一视觉风格。
- 统一按钮、输入框、选择框、表格、页签、弹窗与侧滑面板；保留原有组件属性转发、事件、表单值和禁用条件。
- 首页优化指标卡、项目组合表格、跟进摘要与流程分布的层级；项目列表保留全部数据列和操作入口。
- 成本页将版本信息、保存导出、视图切换及年度/录入工具分区，兼顾高密度录入；人员表格的列宽、固定列和拖动行为保持原实现。
- 项目流程优化节点状态、项目信息、归档与文档操作的布局；长路径和文件名可换行，文档按钮按可用宽度排列。
- 主数据、报价、CPQ、维保、提醒及历史评审统一卡片、编辑工具栏、表格和空状态样式。
- 增强键盘焦点、选中状态和保存反馈；弹窗支持可用视口内滚动，并遵循系统减少动态效果的偏好。

公共样式集中在 `app/globals.css`，公共控件在 `components/ui` 与 `components/workbench`；各业务页面引用统一的面板、工具栏和滚动容器样式。

## 自检发现与修正

1. 搜索框调整过程中出现桌面断点后移：恢复原来的 `xl` 可见范围，并实测 1280px 宽度搜索及清除结果。
2. 通用表头背景影响成本报表白字对比度：将默认背景放到表头组，保留深色行背景覆盖；浏览器确认白字对应深蓝底色。
3. 项目表格固定首列可能遮挡手机右侧操作：仅在 `sm` 及以上固定，手机保持整表横向滚动，并实际打开、取消项目编辑弹窗。
4. 成本页顶部留白过大：缩小成本专用卡片、费率工具栏和区块间距，保留全部字段和按钮。
5. 窄屏长路径与金额易被旁边按钮、图标挤压：路径按空间换行，金额使用卡片完整宽度，保留信息完整性。
6. 保存状态的辅助角色被 Lint 提示可使用原生语义：改为 `output` 元素，不改变保存行为。
