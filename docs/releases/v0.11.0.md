# v0.11.0 · 离线计算草稿与分包站型工作表

## 更新内容

- 集成 Univer 1.0.3，新增英文 Calculation Drafts 入口，可使用 SUM、SUMIF、SUMPRODUCT 等公式。
- Download backup、Save draft 和保存状态合并到 Start / Formulas / View 菜单行，移除额外标题栏，表格使用剩余屏幕空间。
- 修复单击单元格后不能直接输入的问题，恢复正常键盘焦点。
- 分包成本按站型分别显示工作表，Overview 和 Shared / One-off Project Costs 独立显示。
- 公式草稿与正式成本分开保存，点击 Apply to costs 后校验并回填数值。保留既有年度涨幅、站点数量、金额计算及版本锁定规则。
- 草稿保存在本地 SQLite，支持保存冲突检查、浏览器恢复副本和 JSON 备份下载。
- 显式固定运行依赖 rxjs 7.8.2，避免部分离线安装遗漏 Univer 的 peer dependency。

此前 main 分支的成本显示、列宽保存和维保导入改进也包含在此版本中。

## 安装与升级

需要 Node.js 22.18.0 或更新版本。先执行 `npm run backup:local` 并停止旧服务。

Git 用户可在工作区干净时执行 `git pull --ff-only`。ZIP 用户解压源码包到新目录，保留原安装的完整 `data/`、本地配置和所需输出文件。源码包将项目级 Skill 链接展开为普通目录。

在可访问 npm 或内网 npm 镜像的环境中：

```sh
npm ci
npm run build
npm start
```

开发模式仍可使用 `npm run dev`。已有项目无需重新 seed。草稿使用新的 `calculation_drafts` 表，既有成本数据保留。

## 断网环境与 RxJS 修复

源码 ZIP 不包含 node_modules。仅更新 Git 源码不会自动补齐旧安装的依赖。完整安装须提前准备与目标操作系统匹配的依赖；npm ci --offline 仅适用于缓存完整的环境。

若现有安装报 `Failed to resolve import "rxjs"`，可使用本发布附带的 `univer-rxjs-offline-fix.zip`：

1. 停止平台，将补包解压至临时目录。
2. 将其中的 node_modules/rxjs 和 node_modules/tslib 两个完整目录复制到项目 node_modules 下；已有同名目录先移走备份。不要替换整个 node_modules。
3. 在项目目录执行：

```sh
node -e "require('fs').rmSync('node_modules/.vite',{recursive:true,force:true})"
node -p "require.resolve('rxjs')"
npm run dev
```

确认第二条命令输出文件路径，启动后强制刷新浏览器。补包只修复这两个 JavaScript 依赖，不是完整离线安装包，不包含业务数据。

编辑器、公式引擎、英文界面和草稿保存使用本地资源。未配置云协作或远程计算服务。详见 [计算草稿说明](../calculation-drafts.md)。
