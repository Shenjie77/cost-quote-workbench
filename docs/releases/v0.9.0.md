# v0.9.0 · 自定义成本分组、表格布局导出与项目挂起

## 更新内容

- **独立 Group 分组。** 人员行新增自定义组名，与 Scope 分开维护。同组可包含 HLD、LLD、Network planning 等不同工作项；页面可逐行修改，也可通过组头重命名或合并。已有未填写组名的行显示为 Unassigned Group，不按 Scope 自动归组。
- **行排序与列设置。** Action 固定在表格右侧，支持上下移动、拖动排序；开启 Groups 后，跨组拖放同时调整归属。Columns 可设置各列及 Y1–Y5 字段的显隐和左右顺序，保留紧凑表格及年度切换。组名和行顺序随成本版本保存，列偏好保存在本机浏览器。
- **Bulk Entry。** 粘贴 Excel 表格、CSV 或 Markdown 表格后，识别 Group、Scope、BU、RE Type 和年度工作量，预览计算结果并确认录入。Group 与 Scope 向下填充分别控制；成本按当前版本捕获的费率和 allowance 计算。支持中文组名及中英文表头，不采用粘贴的成本单价作为计算依据。
- **按当前表格简易导出。** 浏览器 Simple Export 的 Cost Detail 跟随当前分组、行顺序、列显隐与排序、所选年份；切换到 Summary 后仍保留布局。操作按钮、Check 和后台来源字段不输出。Total 列、多维汇总与 Cost Statement 保留完整五年口径，并在 Excel 注明；旧 RE 分包行单列 Legacy Subcon，结构化 Subcon 明细继续保留。Full Export 与 CLI 简易导出维持标准布局。
- **项目创建与通知。** 手动新建项目开放 Project ID，可填写自定义编号或使用自动编号；界面和 CLI 统一检查格式及唯一性。操作通知移到右下角，默认三秒消失，新通知不会被旧计时器提前关闭。
- **项目挂起。** Project Workflow 提供项目级 On Hold，Project List 标识挂起项目；Today、Agent 和节点提醒暂停监控。恢复时补偿挂起期间的流程时限，保留节点进度；挂起期间新建成本版本也保持项目挂起状态。
- **流程节点编辑。** 编辑器按实际节点数量显示 Steps / Phases，顶部及底部可继续添加节点，不固定显示十个节点；预览发布和既有流程保护规则继续适用。

## CLI 与版本保护

按版本读取和修改人员行，无需读取整个 workspace：

```sh
npm run --silent cost-cli -- cost get --project-id ID --version Vn --section rows
npm run --silent cost-cli -- cost update --project-id ID --version Vn --section rows --input REQUEST --expected-revision REVISION
```

`changes.upsert` 支持独立 `groupName`；可选 `changes.order` 按 ID 排序，必须恰好包含本次增删后全部人员行，不含旧分包行。重复、遗漏、未知 ID 或 revision 冲突会拒绝整次更新。组名与排序不改变已保存工作量、金额或导入来源；旧分包行保留原位置。详见 [CLI 手册](../cli-control-manual.md) 和 [人员录入与导出说明](../personnel-entry.md)。

Confirmed／DRB 仍只锁定对应成本版本的写入。锁定版本可调整分组显示、列设置和年度视图并导出；修改组名、行顺序或工作量需使用可编辑 Draft。全局主数据更新不会重算历史版本。

## 安装与升级

需要 Node.js **22.18.0 或更新版本**。发布提供源码 ZIP 和 SHA-256 校验文件，ZIP 中 19 个项目级 Skill 入口展开为普通目录；Git 仓库保留链接。

已有安装先执行 `npm run backup:local`，再停止旧服务。Git 用户在工作区干净时运行 `git pull --ff-only`；ZIP 用户解压到新目录，保留原安装的完整 `data/`、所需输出文件和本地配置。

```sh
npm ci
npm run build
npm start
```

访问 `http://localhost:3000/`。已有项目无需重新 seed；数据库保持 **schema 8**，新字段兼容旧快照。Skill 列表未刷新时重新打开项目任务。
