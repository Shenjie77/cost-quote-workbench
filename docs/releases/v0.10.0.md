# v0.10.0 · 成本配置保存、MD 批量录入与科目汇总

## 更新内容

- **成本页 Save。** 成本工具栏和顶部 Save 使用同一保存入口，先保存当前成本输入，再保存显示配置。3% allowance、HQ Travel、工作量、组名和行顺序随成本版本保存在本地数据库；年份、分组显示、列显隐及列顺序按项目和成本版本保存在当前浏览器，刷新后恢复。未保存的布局显示 View not saved，旧全局列偏好仅作为初始默认值。
- **MD 固定录入格式。** Bulk Entry 增加 Scope + MD、Group + Scope + MD 两种无表头格式和可复制模板。缺少 BU、RE Type 或年度时可选择默认值，默认采用 Direct MD；确认前展示预览并校验所用费率。支持 `1 MD`、`3days`、`3天`、千位分隔、中英文人天表头、匹配的年度标签及双层年度表头。
- **Markdown 表格识别。** 支持管道表格、对齐分隔行、完整 Markdown 代码围栏，以及加粗或反引号包裹的表头；保留业务描述和原始行号。未闭合围栏、无法确定的年度或无效数值需修正后确认，成本及单价列仍不作为人天或权威成本导入。
- **按 Cost Statement 科目汇总。** Cost Statement 默认排在多维汇总首位。设备、Logistics、外部人力、Travel、Settlement、EHS 和 Risk 使用对应报表科目，替代通用 Unassigned 金额；父子科目只计算一次。
- **Subcon 汇总。** 新增 Subcon 页签，将历史 RE 分包与结构化 BOQ 汇总对齐至 **2.3.2**；Scope 和 BU 保留业务维度，RE 维度合并分包。简易导出增加 Summary Subcon。
- **界面文案。** 移除 Personal 字样，成本表及相关入口统一使用 Cost Input、Add Row、Cost Columns 等简洁名称。

## 保存、导出与版本保护

调整成本表后点击 **Save**，再刷新即可恢复保存的年度、分组和列配置。显示偏好属于当前浏览器的指定项目及版本，不随数据库备份跨浏览器迁移。成本保存失败或发生 revision 冲突时会提示处理，不会误报显示配置已保存。锁定版本仍可保存显示偏好；修改工作量、组名、行顺序等成本数据仍需可编辑 Draft。

页面及 Simple Export 的多维汇总包含 Risk，并与 **Total Cost with Risk** 对齐；CLI `cost export --format simple` 同步使用这一汇总口径并包含 Summary Subcon，其成本详表仍采用标准布局。浏览器简易导出的成本详表继续跟随当前表格布局。

Full Export 保留原有 Sales Cost 审计与对账页；CLI calculate 的默认维度汇总仍采用 Sales Cost。费率快照、历史成本锁定及主数据隔离规则继续适用。

详见 [成本录入与导出说明](../personnel-entry.md)。

## 安装与升级

需要 Node.js **22.18.0 或更新版本**。发布提供源码 ZIP 和 SHA-256 校验文件，ZIP 中 19 个项目级 Skill 入口展开为普通目录；Git 仓库保留链接。

已有安装先执行 `npm run backup:local`，再停止旧服务。Git 用户在工作区干净时运行 `git pull --ff-only`；ZIP 用户解压到新目录，保留原安装的完整 `data/`、所需输出文件和本地配置。

```sh
npm ci
npm run build
npm start
```

访问 `http://localhost:3000/`。已有项目无需重新 seed；数据库保持 **schema 8**。本次显示偏好使用浏览器存储，不修改历史成本快照。
