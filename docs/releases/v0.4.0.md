# v0.4.0 · 项目操作与 Skill 细分入口

## 更新内容

- 项目列表最后新增 Action / 操作列，Edit 与 Del 并排显示。Edit 修改项目名称和客户；Del 经确认后移除项目，保留本地成本、报价及评审归档，支持 CLI 恢复。
- 删除后旧自动保存和 seed 无法重新创建同一项目。最后一个项目删除后仍可新建；删除冲突或外部删除提供重新加载入口。
- 新增 `project / cost / masterdata / cpq / quote / ssr / boq` 的分区读取和更新。支持按 ID、关键词和分页读取，只提交指定字段或条目。
- Masterdata 八个页签可独立维护；成本可以按版本、行、费率与设置操作。成本校验、计算和 Excel 导出可直接指定项目和版本。
- 原有 CPQ、Excel 导入、SSR 及维保归档命令支持 `--compact`。Skill 默认使用细分入口，避免完整工作区往返。
- DRB 通过且条件关闭、明确完成 DRB/成本基线节点，或成本定稿（Confirmed）后，锁定项目成本输入和 RE 费率。网页、CLI 和导入均执行服务端校验。修改流程标签不会解除锁定。
- DRB 已锁定的 Draft/Suspended 成本仍可在不改动输入的情况下标记为 Confirmed，以继续报价。报价、T&C 维护、查看和导出仍可使用。
- SQLite 数据结构升级至 3；兼容迁移按数据库版本执行，避免每次 CLI 调用扫描全部工作区。

## 验证

已通过 96 项自动测试、Lint、TypeScript 类型检查、生产构建和 Skill 格式校验。

## 安装与升级

本版本提供源码 ZIP，需要 Node.js **22.18.0 或更新版本**。

已有安装先在原目录运行 `npm run backup:local`，再停止旧服务。使用 Git 更新时在工作区干净的情况下运行 `git pull --ff-only`；使用 ZIP 更新时解压到新目录，在旧服务停止后保留原安装的完整 `data/` 目录，以及需要保留的 `outputs/` 和本地配置。请勿用空目录覆盖原业务数据。

```sh
npm ci
npm run build
npm start
```

访问 `http://localhost:3000/`。首次启动会进行本地数据库迁移；已有项目不需要运行 seed。全新安装可直接创建空白项目，`npm run seed:local` 仅用于明确需要演示项目的场景。

已删除项目可使用以下命令查询和恢复：

```sh
npm run --silent cost-cli -- project list --deleted
npm run --silent cost-cli -- project restore --project-id ID --expected-revision REVISION
```

## 打包范围

发布 ZIP 来自本版本 Git 提交，包含源码、锁定依赖清单、Skill、文档和测试资料。它不包含 `node_modules/`、构建输出、真实业务数据库、备份、导出的 Excel 或本地环境配置。安装依赖和构建需在目标电脑执行。

程序仍使用本地 SQLite；本版本不接入公司 CPQ/审批系统，也不自动发送 PM 提醒消息。完整工作区接口保留兼容，细分入口使用方法见 [Skill 细分资源说明](../../skills/cost-workbench/references/resources.md)。
