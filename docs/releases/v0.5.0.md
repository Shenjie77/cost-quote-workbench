# v0.5.0 · 业务 Skill 拆分与年度成本计算

## 更新内容

- 按项目管理、主数据维护、成本编制、CPQ、维保、商业报价、流程评审和历史参考拆分为 **18 个独立业务 skill**，另保留 `cost-workbench` 跨业务入口。各入口有中文名称和调用示例，可直接按业务调用，按需读取目标项目、版本或页签。
- 报价编制、报价模板更新、报价导出分开调用；RE Type、分包、补充成本、维保参考、CPQ 目录、风险假设、流程配置和实际流程更新各有独立入口。完整列表见 [业务 Skill 清单](../business-skills.md)。
- `project create` 可从项目号、名称、客户创建空白 V1；`cost create` 可新建空白或复制指定版本为 Draft，保留当前活动版本，不覆盖已有或已删除项目，也不能绕过成本锁。
- `cost import --version Vn` 可预览并导入指定成本版本。非活动版本的导入不改变当前编辑器；预览返回版本和 revision，`--compact` 返回局部收据，保留未使用 compact 的旧接口兼容。
- 修正成本锁范围：DRB 完成或成本定稿锁住项目成本及其捕获费率，**Master Data Resources 仍可刷新**。目录维护不会改动任何版本的已计算成本；应用主数据费率、成本更新和导入仍受锁定保护。
- Cost Input 新增可选 **Local + ARP allowance 3%**。开启后，LOCAL/ARP 的 Y1–Y5 Cost 按实际人天 × 版本费率 × 年度调整系数 × 1.03 计算，并逐单元格保留两位小数。反复保存不会重复加算；HQ、分包、差旅及手工费用不加该 3%。
- Summary、历史参考、报价及 Excel 直接汇总计算后的成本，不单列 allowance 层级或再次追加 3%；Excel 假设页记录开关状态。TD 导入已映射成本列时会校验口径差异。

## 验证

已通过 111 项自动测试、Lint、TypeScript 类型检查、生产构建，以及 19 个 Skill（18 个业务入口与总入口）的格式、引用和注册校验。独立隔离试用覆盖锁定后 RE 维护、CPQ 目录维护、流程进度更新。

## 安装与升级

提供源码 ZIP 与 SHA-256 校验文件，需要 Node.js **22.18.0 或更新版本**。ZIP 中项目级 Skill 入口展开为普通目录，便于直接解压使用；Git 仓库中仍保留指向正文的链接。

已有安装先在原目录运行 `npm run backup:local`，再停止旧服务。Git 用户在工作区干净时使用 `git pull --ff-only`；ZIP 用户解压到新目录，在旧服务停止后保留原安装的完整 `data/`、需要的 `outputs/` 和本地配置，避免用空目录覆盖业务数据。

```sh
npm ci
npm run build
npm start
```

访问 `http://localhost:3000/`。已有项目不需要重新 seed；全新安装可创建空白项目。当前数据库结构仍为版本 3，本次不批量重写已锁定成本或历史归档。

在本项目任务中输入 `$ssr-` 选择业务；技能列表未刷新时重新打开项目任务。成本新建返回的版本不会自动切换为 activeVersion，后续更新/导入应显式指定版本；当前客户报价及公司模板填充使用 activeVersion，需核对目标版本。

## 打包范围

发布包来源于本版本 Git 提交，包含源码、依赖锁文件、业务 Skill、文档和测试资料。不包含真实业务 SQLite、备份、导出 Excel、本地环境配置、`node_modules/` 或构建结果；依赖安装和构建在目标电脑执行。SHA-256 文件可用于核对下载完整性。

公司 CPQ 与正式审批仍在公司平台完成；本地流程登记和导出不代表已审批或已发送客户。提醒依赖本地 API 运行，不是 Skill 自身常驻。
