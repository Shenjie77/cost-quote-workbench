# v0.8.0 · 可配置项目流程与结构化成本录入

## 更新内容

- **统一 Project Workflow。** Today、项目流程和 Agent 使用同一份执行记录，旧 SSR 评审保留只读历史。节点支持自定义顺序、并行阶段、关键节点、必填确认、跳过、暂停和恢复；行为由节点属性决定，不依赖显示名称。配置结束节点完成后停止本轮提醒。
- **SLA 与全局同步。** 每个节点分别配置工作日或自然日 SLA、节假日和提醒开关。期限内普通跟进，截止日优先处理，超过准确截止时间列为紧急任务。全局节点修改先预览，再按全局及项目修订号原子发布；Today 分布与项目操作页同步，默认保留正在执行的期限和完成历史。
- **独立流程操作页。** Project Workflow 与成本页采用一致的项目选择方式；紧凑英文信息栏整合 Proposal Number、iSales 和 CPQ 跳转链接。成本版本信息精简为英文，Version Delta 可直接切换查看版本；查看旧成本不移动当前流程轮次。
- **结构化 Subcon 成本。** Cost Workspace 新增 Subcon 页签。小项目按条目录入 Y1–Y5 数量；大项目维护站型 BOQ、每站数量及年度部署数，并单列项目共用费用，自动汇入 **2.3.2**。支持批量选择目录、保存后才新增的手工条目、单年集中录入、站型配置复制和年度成本展开查看。
- **分包目录与价格快照。** Master Data → Subcontract 直接维护单位和参考单价，移除 Supplier、Pricing Basis 的显示和必填要求。已采用条目保留本版本单价，刷新目录不覆盖成本；缺失价格与明确零价分开处理。新分包使用 Subcon，旧 RE 手输分包金额继续保留、只读展示，在未锁定版本可明确删除被替代行。简易及完整 Excel 按实际 BOQ 增加分包明细与适用的站型年度计划表。
- **人员成本紧凑录入。** Personnel Input 改为直接编辑的表格，移除搜索栏；All/Y1–Y5 年份切换旁提供统一 **Mode：Sites / Direct MD**，切换可能清除已填人天时先明确确认。项目日期显示为 **Proj Start / Proj End**。3% allowance 按 **LOCAL、ARP、HQ、OTHER Pool** 选择，同一 Pool 的各人员等级统一计入年度成本；HQ Travel 单独启用。新空白版本默认关闭两项，复制版本保留原计算方式。

## CLI、Skill 与历史保护

18 个业务 Skill 及 `cost-workbench` 路由同步更新。全局目录继续按页签独立维护，成本按项目及版本窄读写；流程配置发布负责评估受影响项目，日常目录更新不读取整个 workspace。

```sh
# 独立维护全局分包参考目录
npm run --silent cost-cli -- masterdata get --tab subcontract --limit 20

# 读取一个版本的分包 BOQ 或人员/差旅设置
npm run --silent cost-cli -- cost get --project-id ID --version Vn --section subcontract
npm run --silent cost-cli -- cost get --project-id ID --version Vn --section settings

# 查看统一流程计划；修改定义先预览再发布
npm run --silent cost-cli -- project get --project-id ID --section workflow-plan
npm run --silent cost-cli -- workflow preview --input preview.json --expected-revision GLOBAL_R
```

`cost update --section subcontract` 接受结构化条目与站型数组，成本由系统计算；`--section settings` 使用 `rateSettings.allowancePools` 和 `travelSettings.enabled`。请求信封、修订号及发布动作见 [CLI 手册](../cli-control-manual.md)、[项目流程](../project-workflow.md) 和[分包设计](../subcontract-cost-design.md)。

Confirmed／DRB 仅保护对应成本版本；锁定版仍可查看汇总、比较、导出或复制为新 Draft。新 Draft 使用最新全局流程模板开启独立轮次，进入要求定稿的节点前仍需确认本轮成本。全局费率、分包目录及流程发布不会修改历史成本金额；显式 Apply Master Rates 只更新指定可编辑版本，并同步当前编辑数据。

历史按单个 RE Type 选择的 3% 和旧 Local/ARP 开关继续按原范围计算，读取或复制不会自动扩大到整个 Pool。旧 CLI 设置调用保留兼容；只有主动修改对应版本的选项才更新适用范围。旧版缺少 HQ Travel 开关时同样保留原差旅口径。

## 安装与升级

需要 Node.js **22.18.0 或更新版本**。发布提供源码 ZIP 和 SHA-256 校验文件；ZIP 中 19 个项目级 Skill 入口展开为普通目录，Git 仓库保留链接。

已有安装先执行 `npm run backup:local`，再停止旧服务。Git 用户在工作区干净时运行 `git pull --ff-only`；ZIP 用户解压到新目录，在旧服务停止后保留原安装的完整 `data/`、所需输出文件及本地配置。

```sh
npm ci
npm run build
npm start
```

访问 `http://localhost:3000/`。已有项目无需重新 seed；Skill 列表未刷新时重新打开项目任务。数据库自动升级至 **schema 8**，保留原始迁移归档、成本快照和旧评审证据。升级不会把最新主数据自动套入旧成本；回退程序应配合升级前备份。
