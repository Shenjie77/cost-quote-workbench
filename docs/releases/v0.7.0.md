# v0.7.0 · 独立主数据与成本版本工具

## 更新内容

- **Master Data 独立于项目。** 九个全局页签分别维护和保存修订号，CLI / Skill 无需读取项目或整个 workspace。更新目录不会改变已有项目，包括 Draft；新项目和空白成本版本捕获当前数据，复制版本保留源版快照。
- **显式应用最新数据。** 成本页“计算口径”内增加应用最新主数据按钮，仅对未锁定 Draft 重新捕获人员费率和计算成本。相关项目目录也通过明确的应用操作更新，历史报价和归档保持原样。
- **RE Type 分类可见、可编辑。** 手动设置 Category、Pool、Level、Code 和 Name，新增默认自有 LOCAL/L1；切换分包时清除人员层级和 HQ 差旅标记。自定义编码与分类独立，不再自动归类为分包。
- **成本版本状态和删除。** 顶部增加版本状态栏；未锁定的 Suspended 版本可删除，至少保留一个可见版本。删除保留不可变成本及流程快照、评审和报价来源，编号不复用。当前版本或流程版本被删除时恢复剩余版本的既有记录。Confirmed 和历史锁定版本受保护。
- **简易成本 Excel 导出。** 新增成本详表、Scope、BU、RE Type 和 Cost Statement 五张业务表，按页面展示年度投入、成本和汇总。Report Item 中英文同格，去除技术字段和 Source 列；完整九页工作簿继续保留。锁定版本可以只读导出。
- **2.3.4.2 默认 1%。** 新空白成本按 2.3.1 人力成本合计（自有、非自有及 HQ 差旅，不含分包）的 1% 计算，支持直接输入金额改为手工，也可一键恢复自动。2.3.1 继续自动汇总；旧版已保存金额不回填，复制版本保留原模式。

## CLI 与 Skill

18 个业务 Skill 和跨业务路由同步更新，继续按项目、版本或全局页签窄读写：

```sh
# 独立全局目录：无需项目号
npm run --silent cost-cli -- masterdata get --tab resources

# 明确将最新人员费率用于一个草稿
npm run --silent cost-cli -- cost apply-rates --project-id ID --version Vn --expected-revision R

# 删除未锁定的暂停版本，以及只读追溯
npm run --silent cost-cli -- cost delete --project-id ID --version Vn --expected-revision R
npm run --silent cost-cli -- cost get --project-id ID --section deleted-versions
npm run --silent cost-cli -- cost get --project-id ID --section archive --version Vn

# 按页面导出；省略 format 或 full 仍为完整九页格式
npm run --silent cost-cli -- cost export --project-id ID --version Vn --format simple --output outputs/Cost-simple.xlsx
```

`masterdata get/update` 现在操作全局目录，不接受项目号；返回独立页签 revision，不能使用项目 revision 更新。旧项目采用的目录应从对应项目资源读取。成本设置中 `manualCosts.otherServiceRate:0.01` 表示 1%；只设置 `manualCosts.otherService` 时自动退出比例模式。

## 安装与升级

需要 Node.js **22.18.0 或更新版本**。发布源码 ZIP 和 SHA-256 校验文件；ZIP 中 19 个项目级 Skill 入口展开为普通目录，Git 仓库保留链接。

已有安装先运行 `npm run backup:local`，再停止旧服务。Git 用户在工作区干净时运行 `git pull --ff-only`；ZIP 用户解压到新目录，在旧服务停止后保留原安装的完整 `data/`、所需 `outputs/` 和本地配置。

```sh
npm ci
npm run build
npm start
```

访问 `http://localhost:3000/`。已有项目无需重新 seed。Skill 列表未刷新时重新打开项目任务。

数据库自动升级至 **schema 6**，一次性建立全局主数据表。初始化从已有项目目录提取可复用条目，已有项目文档及成本快照不被重写。同编码或 ID 的内容有差异时，保留冲突及来源，由用户确定正确全局条目；尚未解决的相关冲突会阻止新项目创建或显式应用，旧项目仍可按原快照查看和工作。迁移不会自动选取最新项目值或把新费率套到历史成本。回退程序应使用升级前备份。
