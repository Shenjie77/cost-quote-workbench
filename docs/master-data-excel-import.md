# Master Data Excel 批量导入

每个可见页签的搜索与保存工具栏均提供 **Excel Template** 和 **Bulk Import**：CPQ Catalog、RE Types、Subcontract、Supplemental、Maintenance、Assumptions、Quote Templates、Profit Share、Workflow。兼容保留的 Status 字典也有相同格式支持。

## 使用方式

1. 在需要维护的页签点击 **Excel Template**，下载该页签的空白 `.xlsx` 模板。
2. 阅读 **Guide** 中的字段说明、必填条件、选项与示例，在 **Data** 的第二行起填写。第一行为固定字段名，列可调整顺序，字段名与模板标识需要保留。Guide 的示例不会作为业务数据导入。
3. 若需要批量修改已有记录，打开 **Bulk Import → Export Current Data**。下载的文件包含当前草稿和原始 ID，修改后重新导入。
4. 选择文件后查看新增、更新、未改变的数量和逐行预览。错误会指出 Excel 行号或单元格；存在错误时整批无法应用。
5. 点击 **Import to Draft** 导入当前页签草稿，再使用原有 **Save this tab** 保存。Workflow 继续使用 **Preview & Publish**，核对项目影响后发布。

文件在浏览器本地解析；没有外部上传服务。导入预览及取消不写数据库。文件最大 20 MB，最多 10,000 条数据；不接受公式、Excel 错误值或其他页签的模板。含公式的源表请先粘贴为值。

## 合并规则

- 文件未出现的记录始终保留，不提供批量删除或全表替换。
- 已有 ID 更新对应记录；RE Types、Subcontract、Supplemental 也可通过原业务 Code 匹配并保留 ID。身份相互冲突或重复时拒绝整批导入。
- Profit Share 通过 ID 或规范化后的 BU 名称匹配。BU Code 只是公司参考编码，可重复，文本形式保留前导零，不参与系统匹配。
- 新记录的 ID 可留空，由系统生成。Workflow 新节点的 Code 也可留空，生成后保留该 Code 才能在后续导入时更新同一节点。
- 更新已有记录时，空白单元格保留原值；`0` 和 `FALSE` 是明确的值。列表可使用换行、分号或 JSON 字符串数组，`[]` 表示清空列表。清空普通文本仍可在原编辑表格中完成。
- 新记录采用 Guide 中说明的默认值；必填字段、类型、范围、业务编码、日期和引用会校验。当前草稿已有错误也须先修正。
- 当前页签或引用目录在预览后发生变化，需要重新选择文件预览；原有保存 revision 冲突保护继续生效。

## 现有功能保护

- 导入只维护全局目录草稿，不自动更改已有项目的成本、报价或参考快照。
- Quote Templates 的表格字段保持英文，既有客户 Excel 文件绑定、单元格映射及旧翻译元数据均保留。表格导入不替代客户 `.xlsx` 模板的独立上传与映射功能。
- 报价模板引用的假设必须已保存到全局 Assumptions；未保存的新假设草稿不能当作已存在引用。
- Workflow 只导入节点定义，不导入项目实际状态、日期、进展或完成证据。最终节点拓扑、顺序约束和受影响项目仍由原发布流程校验；文件夹设置继续遵循仅影响新项目的既有规则。
- 取消、切换页签及卸载页面均会丢弃尚未应用的预览；异步文件读取不能落入另一个页签。
